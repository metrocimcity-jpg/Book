# Stage 3 — Gather artwork for every taxon (no generation)

Write `mammals/scripts/fetch-images.mjs`. It walks `data/mammals.json` and acquires one
image per **order**, **family**, and **genus** node, stores it locally, and records full
provenance.

> **Absolute rule:** images are *found and downloaded* from free-licence sources.
> Nothing is generated by an image model, ever. If no acceptable image exists for a
> taxon, use the placeholder and log the gap — do not substitute a lookalike species
> from a different family, and do not invent a file.

## Preference order (illustrations first)

1. **PhyloPic** — CC vector/raster silhouettes keyed to taxonomic names. API v2 at
   `https://api.phylopic.org` (docs: <https://api-docs.phylopic.org/v2/>). This is the
   primary source: it resolves *by taxon name at any rank*, which is exactly the problem
   we have. Query the name index, then the image record; take the largest raster plus
   the vector when available. Honour its attribution rules
   (<https://www.phylopic.org/articles> → licensing).
2. **Biodiversity Heritage Library** (`https://www.biodiversitylibrary.org/api3`, free API
   key, or its Flickr stream) — public-domain scientific plates. Best-quality illustrated
   option for orders and families.
3. **Wikimedia Commons** — `https://commons.wikimedia.org/w/api.php`. Search
   `<taxon> illustration|plate|lithograph|drawing` and filter to PD / CC-BY / CC-BY-SA.
   Rich seams: *Brehms Tierleben*, Lydekker's *Royal Natural History*, Audubon's
   *Quadrupeds of North America*, Joseph Wolf and Gustav Mützel plates, Ernst Haeckel's
   *Kunstformen der Natur*.
4. **Openverse** (`https://api.openverse.org/v1/images/`) with `license_type=commercial,modification`
   — broad net, good for odd genera.
5. **Photograph fallback, last resort:** iNaturalist taxon photos
   (`https://api.inaturalist.org/v1/taxa?q=<name>&rank=genus`) restricted to CC0/CC-BY/CC-BY-SA
   observations, or Wikimedia's taxon lead image. Mark these `"kind": "photo"` so the UI
   can label them.

Reject anything with an unclear licence, `CC-BY-NC`, `CC-BY-ND`, or a
"non-free / fair use" tag. When in doubt, skip.

## Resolution strategy per node

- Query by the node's own scientific name first.
- If empty, climb: for a genus, try its type species (`species[0].name`), then the family.
  Record `"resolvedFrom"` when the image is inherited from another rank so the UI can
  caption it honestly ("Illustration of *Panthera leo*, representing *Panthera*").
- Never climb *past* the family for a genus, or past the order for a family — a
  generic "mammal" drawing is worse than the placeholder.

## Processing and output

- Rate-limit: max 2 requests/second per host, a descriptive `User-Agent`
  (`mammals-sunburst/1.0 (+https://example.org; contact@example.org)` — ask the user for
  a real contact string), exponential backoff on 429/5xx.
- Resume-safe: skip any taxon already present in `assets/credits.json` unless `--force`.
- Resize with `sharp` (ask before installing; if declined, store originals and resize in
  CSS) to two derivatives: `@1x` 320px and `@2x` 640px on the long edge, WebP plus a
  fallback PNG. Keep SVG as-is when the source is vector.
- Filenames: `assets/img/<rank>/<name-lowercased-hyphenated>.webp`.
- Strip EXIF. Keep the original bytes in `data/raw/img/` (gitignored).

`assets/credits.json`:

```json
{
  "Panthera": {
    "rank": "genus",
    "kind": "illustration",
    "file": "assets/img/genus/panthera.webp",
    "file2x": "assets/img/genus/panthera@2x.webp",
    "title": "Panthera leo, plate from The Royal Natural History",
    "creator": "Joseph Wolf",
    "license": "PD-old-100",
    "licenseUrl": "https://creativecommons.org/publicdomain/mark/1.0/",
    "source": "Wikimedia Commons",
    "sourceUrl": "https://commons.wikimedia.org/wiki/File:...",
    "resolvedFrom": "Panthera leo",
    "retrievedAt": "2026-09-19"
  }
}
```

Then regenerate `mammals/CREDITS.md` from it: grouped by source, each entry as
`Taxon — Title, Creator (Licence) · link`. This file is the licence compliance record;
it must list **every** downloaded image.

## Placeholder

`assets/img/placeholder.svg`: a neutral hand-drawn-feel silhouette in `currentColor`,
captioned in the UI as "No free illustration found yet". Log all misses to
`data/raw/missing-images.txt` so they can be filled in later by hand.

## Definition of done

- `npm run images` completes and reports: total nodes, resolved, inherited, photo
  fallbacks, missing — with percentages.
- Coverage targets: **100% of orders**, **≥95% of families**, **≥80% of genera**, and
  **≥70% of all resolved images are illustrations rather than photographs.** If a target
  is missed, say so plainly rather than loosening the licence filter.
- `CREDITS.md` regenerated; every entry in `credits.json` has a non-empty
  `license` and `sourceUrl` (assert this, fail non-zero otherwise).
- Paste the summary table and three sample credit entries.
