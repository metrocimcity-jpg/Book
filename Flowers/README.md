# Flowers

Data, colour tokens, and images for the flowers sunburst. Open the repository root and choose **Flowers** (`/?group=flowers`).

Taxonomy: WCVP accepted species with herbaceous lifeforms (perennial, annual, geophyte, and similar), excluding tree/shrub/subshrub — 63 orders, 244 families, 5,384 genera, 106,477 species. Rebuild with `node scripts/build-group.mjs --group=flowers`.

Artwork is gathered, never generated. See [CREDITS.md](CREDITS.md).
