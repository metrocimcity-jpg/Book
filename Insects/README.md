# Insecta

Data, colour tokens, and images for the insect sunburst. Open the repository root and choose **Insects** (`/?group=insects`).

Taxonomy: GBIF Backbone Insecta, **order → family**. Family.value is the accepted-species count (1,102,569 species across 42 orders and 2,113 families). Genera and species names are not listed — a full species dump exceeds GBIF’s search offset limit and the chart budget. Rebuild with `node scripts/build-group.mjs --group=insects`.

Artwork is gathered, never generated. See [CREDITS.md](CREDITS.md).
