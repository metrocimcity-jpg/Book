# Trees

Data, colour tokens, and images for the tree sunburst. Open the repository root and choose **Tree** (`/?group=tree`).

Taxonomy: BGCI GlobalTreeSearch DwC-A (CC-BY-NC 4.0) — 61 orders, 267 families, 4,161 genera, 57,596 species. Family→order mapped with GBIF. Rebuild with `node scripts/build-group.mjs --group=tree`.

Artwork is gathered, never generated. See [CREDITS.md](CREDITS.md).
