# Bushes

Data, colour tokens, and images for the bushes sunburst. Open the repository root and choose **Bushes** (`/?group=bushes`).

Kew WCVP has no lifeform token “bush”. This pack is accepted species whose `lifeform_description` includes **subshrub** — 64 orders, 236 families, 3,428 genera, 43,398 species. Rebuild with `node scripts/build-group.mjs --group=bushes`.

Artwork is gathered, never generated. See [CREDITS.md](CREDITS.md).
