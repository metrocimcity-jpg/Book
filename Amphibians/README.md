# Amphibia

Data, colour tokens, and images for the amphibian sunburst. Open the repository root and choose **Amphibians** (`/?group=amphibians`).

Taxonomy: AmphibiaWeb monthly snapshot `amphib_names_20260401.txt` (CC BY 4.0) — 3 orders, 77 families, 605 genera, 9,014 species. Rebuild with `node scripts/build-group.mjs --group=amphibians`.

Artwork is gathered, never generated. See [CREDITS.md](CREDITS.md).
