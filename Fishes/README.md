# Fishes

Data, colour tokens, and images for the fishes sunburst. Open the repository root and choose **Fishes** (`/?group=fishes`).

Taxonomy: GBIF Backbone accepted species under Chordata fish classes/orders — 63 orders, 716 families, 6,493 genera, 46,114 species (includes taxa GBIF marks extinct; toggle them in the UI). Fishes is a vernacular group, not a clade. Rebuild with `node scripts/build-group.mjs --group=fishes`.

Artwork is gathered, never generated. See [CREDITS.md](CREDITS.md).
