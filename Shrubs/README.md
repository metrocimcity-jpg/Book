# Shrubs

Data, colour tokens, and images for the shrub sunburst. Open the repository root and choose **Shrubs** (`/?group=shrubs`).

Taxonomy: WCVP accepted species whose lifeform includes **shrub** — 66 orders, 301 families, 4,471 genera, 57,321 species. Rebuild with `node scripts/build-group.mjs --group=shrubs`.

Artwork is gathered, never generated. See [CREDITS.md](CREDITS.md).
